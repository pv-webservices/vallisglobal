## Changes made to the supplied wording (and why)

1. **"Every VALLIS fixture is crafted from solid brass and marine-grade SS 304 & SS 316"** → "Our premium ranges are crafted from solid brass, SS 304 and marine-grade SS 316". The client's own catalogue lists zinc-alloy, aluminium, SS 202 and PVC products, so "every fixture" would be inaccurate. Only SS 316 is marine grade, so the wording was corrected.
2. **Competitor brand names removed** (dormakaba, ASSA ABLOY, Häfele, GEZE) from "Certified to global architectural standards". Naming other companies' trademarks in a comparative claim invites legal risk; the claim now refers to "the world's leading architectural hardware brands". Add the specific standards (e.g. EN 1906) once certificates are confirmed — that is stronger SEO and more credible.
3. **"Eliminates premature wear…"** → "designed to resist premature wear…". An absolute guarantee is softened to a design claim.
4. **Finish swatch selector on product pages** was not added: finish availability differs by model, so a selector would imply options that may not exist. Each product page links to the new Finishes page and shows only the finishes documented for it.

## Negative keywords

The site copy contains none of "cheap", "discount", "budget" or "wholesale". `npm run audit:seo` now fails if any page uses them.
Add the same words as **negative keywords** in Google Ads (campaign settings → Keywords → Negative keywords).
